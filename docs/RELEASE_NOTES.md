# 摄影师一键选图 · 北斗免费社区版 0.1.0

这是基于已有 PicKing 文件匹配工作流拆分的首个免费开源测试版，不是付费版的解锁包。

## 下载使用

下载 `BeidouPhotoPicker-Free-v0.1.0-Windows.zip`，解压后运行 `BeidouPhotoPicker-Free.exe`。不需要安装 Python、千问模型或激活码。可用 `SHA256SUMS.txt` 核对下载包和程序。

## 本版提供

- 小图找高清图 / RAW：文件名和完整尾号匹配。
- 商家目录优先，多候选标记需核对。
- 保留小图多级目录结构，重名自动另存，不覆盖文件。
- 只复制，不移动或删除原图；每项复制后校验并写入导出清单。
- 中文桌面界面和源码命令行入口。

## 测试与边界

已用合成文件验证目录保留、重复选片、短编号误匹配、同编号冲突、同名 JPG/RAW、缺文件和嵌套目录保护。免费版只匹配文件名，不解码或预览 RAW，尚无 AI 筛图、吊牌识别、款式理解或千问命名。JPG/RAW 同名并存会要求核对，暂不能手选候选。

Windows 输出盘推荐 NTFS；当前导出需要硬链接支持。请先以少量副本核对工作流，不将测试版结果视为无需检查的最终选片。程序暂未数字签名。
