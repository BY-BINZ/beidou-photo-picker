# 免费版与专业版边界

| 功能 | 免费开源社区版 0.1 | 既有付费版 / 专业版迭代方向 |
| --- | --- | --- |
| 文件名、完整尾号匹配 | 已提供 | 继续维护 |
| 原目录结构导出、冲突与失败清单 | 已提供 | 统一到可靠导出引擎 |
| 基础处理量 | 不设收费额度 | 不以数据保护功能作为收费限制 |
| 同名多候选 | 标记需核对，暂不支持手选候选 | 计划增加格式优先、候选预览与确认 |
| EXIF / 感知哈希识别 | 不含 | 既有付费代码存在 |
| 吊牌 OCR、隔断分图 | 不含 | 既有代码存在，先完善独立模型与复核 |
| 图片质量筛选 | 不含 | 既有规则筛选存在，准确性需按场景验证 |
| 款式语义理解 | 不含 | 规划中；现有颜色分段不能等同于可靠语义识别 |
| 千问识图与命名 | 不含 | 从北斗智名整合，尚未发布整合版 |
| 离线签名授权与换机 | 无需授权 | 新授权系统规划中 |
| 云模型与团队席位 | 无 | 需求确认后再开发，不承诺现阶段可用 |

专业版保留私有代码。社区版的安全修复不会故意落后于专业版；原图保护、冲突提示和诚实的结果统计属于基础要求。

专业版售价、升级周期和设备数尚未在这里公布。已有购买以原权益约定为准，待迁移机制验证后发布明确说明。
